# Учебный пример

Исходный `student-hub-suite.zip` перенесён из Downloads в этот каталог.
SHA-256: `cd32c1db5828e17ffb0ce3bddeb7267b9d37f66315ec93b734d8d1598f26427c`.
Это тот же архив, который был развёрнут и проверен при КР2; журнал проверки находится
в [reference-example.md](../reference-example.md). Он содержит backend, Android и JavaFX примера.

Архив игнорируется Git: внутри демонстрационные секреты, IDE/Gradle-кэши и другие
материалы, не требующиеся для сборки Repairly. Для проверки исходника распаковывайте
его отдельно, не поверх рабочей системы и её `.env`.

В backend Repairly за основу взяты инфраструктура Spring Security/JWT, DTO ошибок,
аудит, административные контроллеры, OpenAPI и каркас фильтра из учебного backend.
Они адаптированы в пакет `ru.rtumirea.repairly.backend` и роли VIEWER/EDITOR/ADMIN.
Модель ремонта, миграция прежней БД, правила статусов, CSV-сервис, справочники,
веб-интерфейс и приёмочные проверки реализованы для Repairly.

Дополнительно изменены жизненный цикл JPA-сущностей с назначенными UUID,
транзакционность аудита/массовых операций, блокировка refresh-сессий при ротации,
отзыв access JWT после смены пароля и обработка конфликта optimistic locking.
Учебные слова Student/StudyGroup не используются в публичном API или коде backend.
