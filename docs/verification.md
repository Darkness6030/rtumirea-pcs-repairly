# Проверка КР №2 — 12 октября 2026

## Среда и сборка

- macOS arm64, Temurin JDK 21.0.12.1.
- Maven Wrapper 3.3.4 → Maven 3.9.11, JavaFX 21.0.8, PostgreSQL JDBC 42.7.13.
- Docker Compose 5.1.3, PostgreSQL 17 Alpine.
- База КР №1: прежний volume `repairly_postgres_data`, таблицы и 6 демозаявок сохранены.
- Локальный порт Repairly — `55434` из `.env`, так как `55432` занят.
- Учебный Student Hub проверен отдельно: [порядок и фактический результат](reference-example.md).

## Автоматизированные проверки

С `-Pgui-tests` выполняются **64 проверки**:

| Набор | Количество | Что проверяет |
| --- | ---: | --- |
| InputValidationTest | 25 | Пустые строки, контрольные символы, длина, телефоны, границы стоимости, числовой ввод КР №1 |
| RepairlyTest | 29 | Прежние CRUD, этапы ремонта, связи, ограничения БД, конкурентные записи, параметризованный SQL, XLSX, консольные регрессии |
| Kr2ServiceTest | 6 | Атомарная форма, версия открытой формы, неизменность клиента, совместные фильтры, CSV текущего набора, статистика |
| JavaFxSmokeTest | 4 | Загрузка всех FXML/CSS, фоновый JDBC, поиск и фильтры, числовая сортировка, связанные страницы, формы с ошибками и успешным сохранением, отмена / подтверждение удаления |

Наборы выполнялись на H2 и PostgreSQL: **64 пройдено, 0 ошибок, 0 пропусков**.
Обычная команда без `gui-tests` запускает 60 проверок и не требует графического рабочего стола.
PostgreSQL-тесты используют временные схемы, не меняя `public`.

Команды:

```bash
./mvnw clean verify
./mvnw -Pgui-tests test

# С актуальными реквизитами из .env:
TEST_DB_URL=jdbc:postgresql://localhost:55434/repairly \
TEST_DB_USER=repairly TEST_DB_PASSWORD=repairly_local_dev \
./mvnw -Pgui-tests test
```

Для повторной визуальной проверки FXML-компонентов:

```bash
./mvnw -Pgui-tests -Dtest=JavaFxSmokeTest \
  -Drepairly.screenshots=target/visual-check test
```

Это изображения, отрисованные JavaFX из реального дерева компонентов; они не являются
макетами. Проверяются страницы заявок и статистики, уменьшенный размер окна и формы.
GUI-тесты открывают настоящие окна, работают с контроллерами и проверяют результат в БД.
Инструмент внешнего управления окнами на этой машине возвращал `cgWindowNotFound`
даже для Chrome; поэтому проверка системного FileChooser мышью не заявляется.
Содержимое CSV, выбранный набор, порядок, кавычки, переводы строк и безопасная замена
проверяются отдельно в Kr2ServiceTest.

Основное приложение и JavaFX из учебного архива запускались через `javafx:run`
и завершились без ошибок Maven. Linux/Windows в этой сессии не запускались;
предусмотрены переносимые Maven Wrapper, FXML/CSS и Windows-скрипт.

## Дополнительная проверка перед защитой

Пройти [сценарий демонстрации](kr2-defense.md) на компьютере команды, включая
системный FileChooser, подтверждение удаления и выбранные параметры PostgreSQL.
Первоначальная смена пароля Student Hub остаётся действием пользователя в примере;
Repairly авторизацию не требует, как и приложение КР №1.

Исторический отчёт и команды Gradle для КР №1 доступны в ветке `kr1`.
